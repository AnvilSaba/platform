# 必要なMinecraft通信だけをmc_protocol上に実装する

MCGuildLinkはMinecraft Java 26.3に対象を絞り、`mc_protocol`を通信・符号化の基盤として、本人認証、Configurationダイアログ、結果通知、切断に必要なパケットと接続状態処理をアプリ内のモジュールで実装する。完成したゲームサーバーや広範なパケット実装を持つライブラリを採用するより実装責任は増えるが、不要なパケットやゲーム機能を持ち込まずに済むため、この方式を選ぶ。

Discordでコードを発行し、本人認証済みのMinecraft接続でダイアログに入力する現行フローを維持する。成功・失敗時の表示、切断、無効コード・ブロック済み・紐付け済みの判定と再試行方法も現行に合わせる。

パケットの符号化・復号、状態遷移、紐付け処理は自動テストする。26.3の実クライアントによる本人認証、ダイアログ入力、結果表示・切断は手動で確認する。実クライアントをCIで動かすためのバージョン別Modや認証運用は今回の対象外とする。

PumpkinはGPLのため、採用候補および調査・設計・実装の参照対象から除外する。
