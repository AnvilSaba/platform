# SQLiteからPostgreSQLへ停止時間を設けて移行する

本番切り替えでは旧版を停止してSQLiteのデータをPostgreSQLへ移行・検証し、Rust版を起動する。既存情報、未使用の紐付けコード、設定値を引き継ぎ、設定の配置・形式が変わる部分は移行手順に変換方法を記載する。同時書き込みや二重書き込みによる移行の複雑化を避けるため、無停止移行より停止時間を設ける方式を選ぶ。

移行・起動確認の間は業務書き込みを止め、旧DBで旧版へ切り戻せる手順を整備する。書き込み解禁後のPostgreSQLからSQLiteへの逆移行は今回の対象外とする。この切り戻し範囲は移行手順の要件であり、移行後のすべての時点で旧版へ戻せる保証ではない。

監査ログDBは移行後のイベントから記録し、過去のDiscord投稿は取り込まずDiscord上に残す。本番バックアップ・復旧設計は別作業で扱う。今回整備するのは移行・デプロイ・切り戻しの準備までであり、実際の本番切り替えは別段階で行う。
