# 二段階投稿で表示順と相互リンクを両立する

同時に作成する Message の前方参照・相互リンクには、本文を完成させる前に全リンク先の実 ID が必要となる。設定順に「更新中」を投稿して ID を確保し、その後に本来の本文へ編集することで、表示順とリンク解決を両立する。途中失敗で仮表示が残ることを受け入れ、取得済み ID と未反映状態を state に保持して同じ Message の編集から再開する。

決定日: 2026-09-05〜06。具体的な操作・検証条件は [Feature Spec #2](https://github.com/AnvilSaba/platform/issues/2)。
