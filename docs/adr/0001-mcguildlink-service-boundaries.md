# MCGuildLinkのRust移行でサービスの責務を分ける

Minecraft接続、Discord操作、ホワイトリスト公開を同じアプリで扱う現行構成を、Minecraft接続専用のMCGuildLink、既存の`apps/bot`、独立したpublic-apiに分ける。各サービスはPostgreSQLを利用し、独立してリリースする。利用者の操作を維持しながら、それぞれの責務と変更範囲を分離するためであり、共通クレートは共有の必要性が明らかになった段階で導入する。

DBロールはアプリごとに分け、public-apiは読み取り専用、BotとMCGuildLinkは必要なテーブルだけ変更可能にする。スキーマ変更はsqlxマイグレーションを実行する専用Jobが担当し、アプリ起動時にはスキーマ互換性を確認する。旧新版が共存できる互換期間を設け、非互換の場合は明確なエラーで起動を失敗させる。サービス分離に伴い、スキーマ変更の順序と互換性をリリース時に管理する必要がある。

今回の移行では、多対多の紐付け、未使用コードの期限なし、関連アカウント全体へのブロック、退出時の紐付け削除を維持する。対象Discordサーバーの限定は修正するが、退出・BANのイベント順序への対策は今回は追加しない。紐付けを保持して退出・タイムアウトを参加資格の判定に反映する変更は、将来の別作業とする。
