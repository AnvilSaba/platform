# 削除と新規構築を明示し、予期しない消失では停止する

管理範囲を絞る編集と破壊的な変更を区別するため、Role・Channel 等の宣言省略は管理解除とし、実物の削除には明示指定と削除許可を必要とする。管理メッセージ群内の投稿と管理スレッドは宣言されたコンテンツそのものなので、省略を削除として扱う境界を Feature Spec に定める。

予期しない消失では、自動再作成や同名採用による誤接続を避けて停止する。対応表は論理 ID と Discord ID の対応だけを保持し、削除の完了を別の記録で表現しない。削除が API 成功または現在値の不在で確認できた場合に対応を除去し、応答不明・タイムアウトの場合は対応を維持したまま結果を報告する。管理対象の予期しない消失は引き続き停止する。

決定日: 2026-09-17。対応表を復旧用のワークフロー状態として扱うと、応答不明時の再実行判断と責務が混在し、実際の対応を上書きし得るため、対応表を論理 ID と Discord ID の関係に限定する。具体的な操作・検証条件は [Feature Spec #2](https://github.com/AnvilSaba/platform/issues/2)。
