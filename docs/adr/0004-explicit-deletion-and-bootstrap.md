# 削除と新規構築を明示し、予期しない消失では停止する

管理範囲を絞る編集と破壊的な変更を区別するため、Role・Channel 等の宣言省略は管理解除とし、実物の削除には明示指定と削除許可を必要とする。管理メッセージ群内の投稿と管理スレッドは宣言されたコンテンツそのものなので、省略を削除として扱う境界を Feature Spec に定める。

予期しない消失では、自動再作成や同名採用による誤接続を避けて停止する。削除済み記録により意図した削除と区別し、テスト Guild 等への新規構築は空の対応表から開始する意図を明示させる。

決定日: 2026-09-05〜06。具体的な操作・検証条件は [Feature Spec #2](https://github.com/AnvilSaba/platform/issues/2)。
