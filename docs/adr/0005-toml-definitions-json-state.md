# 人が編集する定義は TOML、対応状態は JSON とする

既存 Bot で使う TOML に編集形式を揃え、名前付きの属性定義と Markdown の複数行本文を記述できるようにする。機械が生成する対応状態は JSON に分け、希望構成と実 ID の対応を混同しない。

必要な表示はテキストと画像なので、任意の Components V2 ツリーの直接宣言は採用しない。入力は定義・state・画像の個別添付とし、現段階の必要量で収まる画像上限を受け入れることで ZIP の梱包・展開を不要にする。

決定日: 2026-09-05〜06。具体的な操作・検証条件は [Feature Spec #2](https://github.com/AnvilSaba/platform/issues/2)。
