# Message の identity と表示順を区別し、順序変更時は後続を再投稿する

見出しの編集で投稿境界や identity が変わらないよう、論理 ID を持つ配列要素を一つの投稿に対応させる。本文の変更は既存 Message の編集とし、追加・削除・並べ替えでは最初の変更位置から管理群の末尾を再投稿する。

a・c の間に b を追加する際、既存 c の本文を b に置き換えると古いリンクが別内容を指してしまう。表示順を優先して b・c を新規投稿し、古いリンクが無効になることを受け入れる。独立 Thread の identity と相互リンクの処理は ADR 0008・0009 に分ける。

決定日: 2026-09-05〜06。具体的な操作・検証条件は [Feature Spec #2](https://github.com/AnvilSaba/platform/issues/2)。
